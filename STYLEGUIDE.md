# Piggy Bank Style Guide

## Colours

- Soft Blue Background: `#dfeaf2`
- Background Overlay: `rgba(255, 255, 255, 0.18)`
- White: `#ffffff`
- Glass Card: `rgba(255, 255, 255, 0.28)`
- Light Blue Border: `#d8e7ef`
- Blue Accent: `#83b6c9`
- Heading Blue: `#3e6f89`
- Muted Purple: `#657399`
- Dark Text: `#29394a`
- Small Text: `#435466`

## Fonts

- Main Font: Arial
- Backup Font: sans-serif

## Font Sizes

- Page Title: 36px
- Section Title: 24px
- Body Text: 16px

## Style Notes

- Use heading blue for main headings.
- Use light blue borders and very transparent glass-style cards.
- Use the background image with a soft blur effect.
- Use muted purple only for small accents.
- Use rounded cards for sections and feature boxes.
- Use simple buttons for important actions.
- Keep the layout simple and easy to read.
